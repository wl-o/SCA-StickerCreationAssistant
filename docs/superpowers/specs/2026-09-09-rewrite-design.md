# 长文改写（贴图号缩略）设计

日期：2026-09-09

## 目标

粘贴长文 → 缩略为微信贴图号标题+文案 → 可选润色 → 标题文字封面 + 可选搜图配图 → 可复制/下载 → 手动入库。

## 约束

- 不带人设
- 不自动入库
- 缩略保精华，正文约 120–220 字
- **核心不是润色，而是重新组织语言，去 AI 味，写得像真人**
- 二次处理：像真人重写 / 更有判断 / 情绪 / 观点 / 口语 / 再压缩

## 写作原则（写入 prompt）

保留核心事实与意图；删除首先其次、综上所述、不仅而且等套话；增加个人判断与节奏感；不造假事实、不装病句。

## 页面

- 路由：`/rewrite`
- 侧栏：改写

## 能力

1. AI 缩略改写（title/content/discussion_hook）
2. AI 润色（无 persona）
3. Canvas 文字封面（3 套模板），下载 PNG
4. 复用搜图配图与下载
5. 复制正文 / 内容+讨论
6. 保存到内容库（可选）
